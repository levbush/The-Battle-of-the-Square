# The Battle of the Square
Turn-based multiplayer strategy game

Так, для всех, у кого чешутся руки (или креветочные части тела) вспомните, что проект нам сдавать меньше, чем чем через две недели, а ещё половина не сделана

Предусмотрена защита высокого уровня: к использованию приложения не допускаются те, кто не может либо запустить его сам, либо дождаться .exe, или разобраться как он работает 

## Состав игры:
    1) начальное окно:
        - начать игру.
        - продолжить игру.
    2) создание игры:
        - размер карты.
        - кол-во игроков.
        - кол-во ботов.
        - сложность ботов если они есть.
    3) игра:
        - сама игра.
        - настройки.
        - технологии.
        - статистика.
        - экран конца игры.

## Игра:
    1) изначально все спавнятся в случайном месте с 5 звёздами и обзором на 5*5 блоков.
    2) можно ходить за юнитов:
        - у каждого юнита своя эксклюзивная характеристика.
        - в лесу и на горах до защита для юнитов.
        - юниты открывают неизведаннкю территорию(туман войны).
    3) можно развивать технологии:
        - цена технологий увеличивается за каждый город на 1.
        - если прокачать тенологию, то вы её сразу получите.
        - если за технологией была неизвестная технология, то после прокачки последней известной технологии .откроится неизвестная технология.
        - дерево технологий можно открыть и закрытия на кнопку H.
    4) можно улучшать города:
        - чтобы прокачать город нужно определённое(написанно рядом с городом) кол-во ед. нас.
        - если прокачать технологии то можно будет открыть технологии для развития населения:
            а) собирательство 1 ед. нас.
            б) охота 1 ед. нас.
            в) лесная хижина 1 ед нас.
            г) горное дело 2 ед. нас.
        - за новый уровень города дают разные баффы.
    5) можно захватывать города и нетральные деревни:
        - для этого надо:
            а) встать на город или деревню.
            б) в след ходу захватить эту постройку.
    6) в игре можно просматривать статистику:
        - для открытия и закрытия статистики нажмите L.
        - в статистике есть множество уникальных статистик
    7) в игре есть музыка:
        - музыка меняется каждые 2 минуты.
    8) в игре есть настройки:
        - для открытия и закрытия настроек нажмите esc.
        - в настроках можно менять громкость музыки.
        - в настройках есть много уникальных функций.
